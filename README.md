# Triangle Transcript — Safari / macOS

Отдельное расширение Safari для копирования транскрипции YouTube одной кнопкой. **Версия 1.1.3.**

Это форк [HelpFreedom/Triangle-Downloader](https://github.com/HelpFreedom/Triangle-Downloader), адаптированный для Safari и ограниченный работой с расшифровкой. История исходного проекта сохранена, исходный репозиторий подключён как `upstream`. Лицензия — [GPL-3.0](LICENSE).

## Что делает

Кнопка **«Скопировать транскрипцию»** находится в панели управления видеоплеером YouTube, в начале правой группы кнопок.

- Получает доступную расшифровку видео и копирует только текст реплик без таймкодов.
- Заменяет переносы строк, табуляции и серии пробелов одним пробелом.
- После успешного копирования показывает зелёную галочку на **1 секунду**.
- Закрывает панель расшифровки и сворачивает описание, если само открыло его. Описание, заранее раскрытое пользователем, остаётся раскрытым.
- При смене видео отменяет незавершённое чтение, чтобы не скопировать текст предыдущего ролика.

Сначала расширение пытается получить текст прямым запросом к YouTube. Если это недоступно, читает встроенную панель расшифровки и восстанавливает интерфейс после копирования. Язык зависит от доступной дорожки и языка, выбранного в панели YouTube.

Если расшифровка недоступна или запись в буфер отклонена, кнопка показывает знак ошибки; пояснение доступно в её подсказке. Пустой текст не заменяет содержимое буфера.

## Скачать и установить

**Требования:** macOS 26+ и Safari с поддержкой Safari Web Extensions. Готовая локальная сборка рассчитана на **Apple Silicon (arm64)**; для Intel доступна сборка из исходников.

1. Скачайте [Triangle Transcript.zip](https://github.com/fskir/Triangle-Transcript-Safari-MacOS/releases/download/v1.1.3/Triangle.Transcript.zip) из [релиза v1.1.3](https://github.com/fskir/Triangle-Transcript-Safari-MacOS/releases/tag/v1.1.3) и распакуйте.
2. Откройте **Triangle Transcript.app**. Можно перенести приложение в «Программы»; Safari использует расширение, встроенное в это приложение.
3. Для этой локальной сборки разрешите неподписанные расширения: меню Safari **«Разработка» → «Разрешить неподписанные расширения» / Allow Unsigned Extensions**. Если меню скрыто, включите функции для веб-разработчиков в **Safari → Настройки → Дополнения / Advanced**.
4. В **Safari → Настройки → Расширения** включите **Triangle Transcript** и разрешите доступ к `www.youtube.com`.
5. Перезагрузите вкладку YouTube и нажмите кнопку **«Скопировать транскрипцию»** в плеере.

После обновления приложения выключите и снова включите расширение в настройках Safari, затем перезагрузите вкладку видео, чтобы Safari подхватил новый код.

Сборка подписана локальной **ad-hoc** подписью; Developer ID и нотариального заверения Apple нет. В App Store приложение не опубликовано. Идентификаторы приложения и расширения: `com.fskir.TriangleTranscriptSafari` и `com.fskir.TriangleTranscriptSafari.Extension`.

## Ограничения и доступ

- Поддерживаются обычные страницы `https://www.youtube.com/watch`; Shorts не поддерживаются.
- Требуется доступная расшифровка YouTube. Расширение не распознаёт аудио самостоятельно.
- Полностью скрытое получение текста не гарантируется для каждого видео: при отказе прямого запроса временно открывается панель расшифровки.
- Извлечение зависит от разметки и внутренних ответов YouTube; при их изменении может потребоваться обновление.
- Разрешения: `clipboardWrite` и доступ к `https://www.youtube.com/*`. Текст обрабатывается в браузере; внешние сервисы и отдельный сервер не используются.

## Сборка из исходников

Нужны macOS SDK 26+, Swift и Python 3. Скрипт использует Command Line Tools; полный Xcode для этого пути сборки не нужен.

```bash
git clone https://github.com/fskir/Triangle-Transcript-Safari-MacOS.git
cd Triangle-Transcript-Safari-MacOS
python3 safari/scripts/generate-project.py
bash safari/scripts/build-clt.sh
```

Результат: `dist/Triangle Transcript.app`. По умолчанию используется архитектура текущего Mac. Для Intel:

```bash
TRIANGLE_BUILD_ARCH=x86_64 bash safari/scripts/build-clt.sh
```

Сборка Intel предусмотрена скриптом, но её работа на реальном Intel Mac не проверялась.

Для упаковки приложения:

```bash
ditto -c -k --sequesterRsrc --keepParent \
  "dist/Triangle Transcript.app" "dist/Triangle Transcript.zip"
```

Также можно открыть `safari/xcode/Triangle Transcript.xcodeproj` в полном Xcode. Для распространения с собственной подписью настройте свою команду разработчика и подписание.

## Проверка

Для автоматических проверок нужен Node.js с поддержкой `node:test`:

```bash
node --check safari/extension/transcript.js
node --check safari/extension/direct.js
node --test safari/qa/transcript.test.cjs
codesign --verify --deep --strict "dist/Triangle Transcript.app"
```

В текущей версии проходят **15 тестов**: извлечение из старой и новой панели, нормализация пробелов, запись в буфер, очистка интерфейса, смена видео, обработка отказов и галочка на 1000 мс. Нативные app/appex собраны для arm64 и проверены локальной подписью.

В Safari 27 на macOS 27.0.1 ранее подтверждены копирование в системный буфер вставкой в TextEdit, положение кнопки и восстановление интерфейса. Точное время галочки в 1.1.3 проверено тестом состояния кнопки. На проверенном видео прямой запрос вернул HTTP 400, а дорожка субтитров — пустой ответ, поэтому использовалась панель. Это не подтверждает работу прямого извлечения для всех видео. Подробности и границы проверки: [VERIFICATION.md](safari/qa/VERIFICATION.md).

## Структура

- `safari/extension/` — Manifest V3, получение текста и кнопка плеера.
- `safari/xcode/` — нативное приложение и Safari Web Extension.
- `safari/scripts/` — генерация проекта и сборка через CLT.
- `safari/qa/` — тесты и отчёт о проверке.
