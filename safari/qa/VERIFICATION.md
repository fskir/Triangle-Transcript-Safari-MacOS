# Проверка Triangle Transcript 1.1.1

Дата: 9 октября 2026. Сборка arm64, SDK 27.0; установленная macOS 27.0.1.

## Требования и доказательства

- Иконка в toolbar плеера: вставляется первым элементом `#movie_player .ytp-right-controls`, как оригинальная кнопка. Подтверждено деревом доступности Safari: кнопка находится внутри YouTube Video Player перед переключателем autoplay; визуально — рядом с кнопками субтитров и настроек. Автоматический тест проверяет расположение и отсутствие дубликатов.
- Галочка вместо уведомления: код меняет только SVG и атрибуты той же кнопки. Автоматический тест проверяет переход busy → success, путь SVG галочки и возврат idle через 2000 мс. Отдельный host/текст уведомления удалены.
- Закрытие и восстановление: вызывается после записи в буфер; закрывается панель расшифровки, а описание сворачивается только при признаке openedDescription. На реальной разметке YouTube обнаружены вложенные элементы #collapse; исправлено на собственную кнопку `:scope > #collapse`. Для замены узла во время загрузки предусмотрен повторный поиск текущего описания. После регистрации и выключения/включения версии 1.1.1 Safari показал свёрнутое описание с кнопкой ...more, без панели расшифровки. Тесты покрывают старую/современную панель, описание пользователя и замену DOM.
- Получение без раскрытия интерфейса: MAIN-скрипт читает endpoint только из данных, соответствующих текущему videoId, делает один ограниченный по времени запрос к тому же YouTube origin и возвращает только текст. Тест проверяет отсутствие открытия описания/панели при успешном прямом ответе. Live-проверка /youtubei/v1/get_transcript на видео PvTyTUkuem8 вернула 400 FAILED_PRECONDITION; дорожка timedtext вернула 200 с пустым телом. Реальный успешный прямой ответ не подтверждён; в этом случае применяется чтение панели. Получение без открытия интерфейса для всех роликов не заявляется.

## Выполненные проверки

- `node --test safari/qa/transcript.test.cjs`: 15 passed, 0 failed.
- `node --check safari/extension/transcript.js` и `node --check safari/extension/direct.js`.
- `bash safari/scripts/build-clt.sh`: нативные app/appex собраны через Swift CLT.
- `codesign --verify --deep --strict`: подпись корректна.
- Проверка равенства упакованных manifest.json, transcript.js, direct.js исходникам.
- `pluginkit -m -A -v -i com.fskir.TriangleTranscriptSafari.Extension`: зарегистрирована 1.1.1 из dist/Triangle Transcript.app; Safari Settings также показывает 1.1.1 и включённое состояние.
- Safari: контрольный текст буфера заменился полным текстом расшифровки, что подтверждено вставкой в отдельный тестовый документ TextEdit; нет таймкодов панели и переводов строк.

## Практические ограничения

Реальная проверка проведена на одном видео и текущей современной разметке YouTube. Старый вариант панели покрыт фикстурой. Сборка ad-hoc, для локального использования; Developer ID и нотариального заверения нет. Shorts не поддерживаются.

## Исправление центрирования — 1.1.2

9 октября 2026: SVG размещён через inline-flex без padding, margin и абсолютного позиционирования; контуры всех четырёх состояний центрированы в viewBox 36×36. Браузерная проверка использовала настоящий transcript.js в восьми изолированных рамках с конфликтующими стилями YouTube. При размерах кнопки 48×36 и 64×48 смещение центра SVG и геометрического центра каждого контура равно [0, 0] пикселей. Вращение загрузки отключено только в проверочной фикстуре для измерения. Вид всех восьми вариантов проверен по снимку. Повторно пройдены 15 тестов, проверка синтаксиса и нативная сборка app/appex.

Версия 1.1.2 зарегистрирована через pluginkit; Safari Settings подтверждает 1.1.2 и включённое состояние после перезапуска расширения. Страница YouTube перезагружена, кнопка «Скопировать транскрипцию» присутствует в плеере. Подпись проверена, ресурсы dist совпадают с исходниками, ZIP обновлён.
